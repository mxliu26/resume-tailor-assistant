`figures/` contains SVG diagrams and editable Mermaid sources. `images/` contains the product walkthrough and three screenshots using synthetic material. `evidence/` contains concise supporting records for scores, reporting conventions, and cases. Full execution logs, private materials, and internal review pages are not included.

Documentation and diagram labels are in English. Original evidence, synthetic inputs and outputs, screenshots, and the product interface retain their original language; translations in the documentation do not replace source records.
