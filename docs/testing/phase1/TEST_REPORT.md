## 代表性验证

- **格式与事实变化分开处理**：调整换行、空白或列表样式时保留身份及确认状态；修改数字、职责或JD内容时重新核对。
- **补问跟随关联变化**：调整经历关联后更新待答问题，保留已填写答案、草稿和事实归属。
- **改写可核对、可恢复**：显示建议与手动编辑差异，检查中文输入、撤销、接受状态以及刷新后的恢复。
- **PDF可对照**：检查双页PDF提取、原页预览、翻页缩放及保存重开。
